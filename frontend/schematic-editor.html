Tips

Dra i kartan för att panorera, scrolla för att zooma.

Dra en hållplats för att flytta den. Håll Shift för att låsa riktningen till 0/45/90 grader.

Dra ett hållplatsnamn för att flytta etiketten.

Dubbelklicka på en markerad sträcka för att lägga till ett knäck. Dubbelklicka på ett knäck för att ta bort det.

Piltangenter flyttar markerad hållplats ett rutsteg (Shift = 5 steg).
